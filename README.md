# إعداد آلة Kali Linux 2026.3 على QEMU

هذا المستودع يشارك مواد الإعداد والتشغيل فقط: سكربت تشغيل QEMU وملف إعداد تثبيت منقّح. لا يتضمن صورة القرص الافتراضي، أو كلمات المرور، أو سجلات التثبيت، أو ملفات Kali الثنائية للمثبت.

## المتطلبات والملفات المحلية

- مضيف Linux بمعمارية x86-64، مع `qemu-system-x86_64` وPython 3.
- صورة قرص Kali مُثبّتة باسم `disk.qcow2` داخل مجلد المشروع. لا تُرفَع هذه الصورة إلى Git.
- ملف محلي باسم `vnc-password.txt` يحتوي كلمة مرور VNC. أنشئه محلياً فقط؛ لا تشارك محتواه ولا ترفعه.

يمكن إنشاء ملف كلمة مرور VNC دون إظهاره في سجل الطرفية:

```bash
cd /path/to/kali-linux-2026.3-vm-setup
umask 077
read -rsp 'VNC password: ' VNC_PASSWORD
printf '\n'
printf '%s' "$VNC_PASSWORD" > vnc-password.txt
unset VNC_PASSWORD
```

## التشغيل

```bash
chmod +x start-kali.sh
./start-kali.sh
```

يستمع VNC على `127.0.0.1:5901`، ويُحوَّل منفذ SSH في الضيف إلى `127.0.0.1:2222` على المضيف. تبقى المنافذ مرتبطة بواجهة loopback؛ لا تغيّرها إلى واجهة عامة ولا تفتحها للإنترنت. تعتمد مصادقة SSH على إعدادات المستخدم داخل صورة الضيف.

## ملف التثبيت المسبق

`preseed.cfg` نموذج إعداد لـ Debian Installer يتضمن إعدادات عامة ومستخدم النظام `kali`. حُذف منه تجزئة كلمة المرور الموجودة في نسخة العمل الأصلية عمداً؛ لذلك لن يعيّن هذا الملف كلمة مرور للمستخدم تلقائياً. أكمل خطوة كلمة المرور أثناء التثبيت. ملفات نواة وقرص الذاكرة للمثبت ليست ضمن المستودع.
